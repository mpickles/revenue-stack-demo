The Claude connection

The team's Claude can query the tested tables in the warehouse.

Read only. It can ask. It cannot write.

Why it is built the way it is

BecauseA bad number must never reach a report.
SoI chose dbt.

A failed test blocks everything after it by default.

BecauseA live warehouse query costs money on every page view.
SoScreens read saved copies of the tested tables.

The warehouse is only asked live for a drill-down, with a size cap.

BecauseAn assistant must never change an ad account.
SoThe Claude connection is read only.

It can ask the tested tables anything. It cannot write.
